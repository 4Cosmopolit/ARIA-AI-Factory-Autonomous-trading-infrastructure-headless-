# CONTRIBUTING.md — Вклад в ARIA AI‑Factory

## Кодекс поведения

ARIA AI‑Factory следует принципу **"Evidence over claims"**. Каждое предложение должно быть подкреплено доказательствами: тестами, бенчмарками или математическим обоснованием.

## Как внести вклад

### 1. Предложение изменений

1. **Создайте Issue** с описанием предлагаемого изменения.
2. **Обсудите** изменение с maintainer'ами.
3. **Создайте Fork** репозитория.
4. **Создайте ветку** с осмысленным именем (например, `feature/new‑detector`).
5. **Внесите изменения**, следуя стандартам кода.
6. **Создайте Pull Request** с описанием изменений и ссылкой на Issue.

### 2. Стандарты кода

- **Python:** следуйте PEP 8.
- **TypeScript:** следуйте стандартам ESLint.
- **Go:** следуйте `gofmt`.
- **Rust:** следуйте `rustfmt`.

### 3. Процесс ревью

Каждый Pull Request проходит трёх‑рецензентский **Blind Review Gate**:

1. **Code Review** — качество кода.
2. **Maintainability Review** — поддерживаемость.
3. **Performance Review** — производительность.

Если ≥2 рецензента находят критические проблемы, PR отклоняется.

### 4. Коммуникация

- Все обсуждения ведутся в Issues и Pull Requests.
- Для срочных вопросов используйте Telegram‑канал ARIA.

### 5. Лицензия

Внося вклад, вы соглашаетесь, что ваш код будет распространяться под лицензией MIT.
