# SKILLS.md — Реестр навыков ARIA AI-Factory

> **Версия:** 12.05.2026  
> **Назначение:** Реестр всех навыков ARIA с прогрессивным раскрытием (L1–L3).  
> **Принцип:** Skills First, MCP as Transport. Каждый навык — изолированный модуль логики.

---

## 1. Навыки качества данных (Data Quality)

| Навык | Уровень | Описание |
|-------|---------|----------|
| `data-quality-audit` | L2 | Входной контроль данных: проверка происхождения, согласованности, свежести. |
| `data-cleansing-pipeline` | L2 | Конвейер очистки: imputation, outlier detection, deduplication, validation. |
| `data-contract-validator` | L2 | Валидация данных по формальным контрактам (единицы, диапазоны, контекст). |
| `self-describing-data` | L2 | Автоматическая семантическая аннотация каждого факта в Temporal KG. |
| `signal-augmentation-engine` | L2 | Обогащение сигналов вычисляемыми полями (прогноз волатильности, рейтинг безопасности хуков). |
| `lineage-tracer` | L2 | Отслеживание происхождения каждого факта (полная карта provenance). |
| `impact-analyzer` | L2 | Анализ влияния изменений в данных на стратегии и агентов. |
| `compliance-verifier` | L2 | Автоматическая подготовка доказательной базы для аудита (GDPR, AI Act). |
| `realism-validator` | L2 | Проверка синтетических данных на соответствие реальным паттернам. |
| `data-debt-detector` | L2 | Мониторинг накопления «долгов» по качеству данных (confidence, просрочка). |

## 2. Навыки безопасности и изоляции

| Навык | Уровень | Описание |
|-------|---------|----------|
| `aria-gov-gateway` + `static-allowlist` | L1 | Единый шлюз безопасности с deny-first политикой и статическим списком разрешений. |
| `permissions-drift-detector` | L2 | Контроль расширения прав навыков при обновлении. |
| `trust-chain-validator` | L2 | Верификация цепочки доверия (агент → навык → зависимости). |
| `model-integrity-checker` | L2 | Проверка целостности весов и кода моделей в памяти. |
| `bitflip-detector` | L2 | Детектор битовых аномалий (Rowhammer, bit-flip атаки). |
| `destructive-command-detector` | L1 | Блокировка деструктивных SQL/Shell команд (DROP, DELETE, rm -rf). |
| `lolbin-detector` | L2 | Обнаружение аномального использования легитимных утилит (curl, git, ssh). |
| `telegram-guard` | L1 | Защита от prompt injection через входящие сообщения Telegram. |
| `phishing-url-scanner` | L2 | Сканер фишинговых URL перед переходом. |
| `approve-guard` | L1 | HITL-подтверждение для всех approve/allowance транзакций. |
| `sandbox-escalation-detector` | L1 | Детектор попыток выхода агента за пределы изоляции. |
| `resource-abuse-detector` | L2 | Детектор аномального потребления CPU/RAM/сети в sandbox. |
| `harness-firewall` | L1 | Второй HITL-фильтр для изменений в конфигурациях обвязки. |
| `prompt-version-lock` | L1 | Версионирование системных инструкций с хеш-контролем. |

## 3. Навыки управления контекстом и памятью

| Навык | Уровень | Описание |
|-------|---------|----------|
| `compress-context` | L1 | Авто-сжатие контекста при занятости >70% окна. |
| `context-length-monitor` | L1 | Принудительное сжатие входящего контекста при превышении лимита. |
| `auto-memory-audit` | L2 | Ежедневный аудит памяти: дубликаты, устаревшие факты, галлюцинации. |
| `context-integrity-daemon` | L1 | Фоновая проверка целостности ключевых параметров сессии. |
| `context-access-simulator` | L2 | Симуляция атаки на утечку контекста в sandbox. |
| `viral-context-injector` | L2 | Вшивание мета-принципов (честность, сжатие, приоритеты) в начало сессии. |

| Навык | Уровень | Описание |

---

> **Прогрессивное раскрытие:**  
> - **L1** — метаданные (~100 токенов), всегда в контексте.  
> - **L2** — инструкции (<5000 токенов), загружаются при активации.  
> - **L3** — ресурсы, загружаются только при явной ссылке.  
>  
> **Доступ:** все навыки доступны через `skills-registry-mcp` и команду `/skill-find` в Telegram.
