# SANDBOX_EVALUATION.md — Оценка песочниц ARIA AI‑Factory v13.01

## Ключевые требования к песочницам
1. **Аппаратная изоляция (KVM/Firecracker)** — критически важные компоненты не должны запускаться в контейнерах.
2. **Мгновенные чекпоинты и откат** — для безопасного тестирования изменений (DeltaBox).
3. **Управление через MCP** — возможность создавать, настраивать и уничтожать sandbox через стандартный протокол.
4. **Egress-контроль** — фильтрация исходящего трафика на уровне ядра.
5. **Мониторинг и аудит** — логирование всех действий внутри sandbox с привязкой к Agent ID + Task ID.

## Сравнение backend-ов

| Критерий | E2B (Firecracker microVM) | Daytona (KVM-based) | Docker.sandbox (Контейнер) |
|----------|--------------------------|---------------------|----------------------------|
| Тип изоляции | Аппаратная (KVM) | Аппаратная (KVM) | Контейнерная (namespaces) |
| Чекпоинты состояния | Да (DeltaBox) | Да | Нет |
| Управление через MCP | Да (Augment Code E2B SDK) | Нет | Нет |
| Оркестрация K8s | Да (KruiseAgents) | Частично | Встроено |
| Egress контроль | E2B Firewall | Daytona Policies | Стандартный Docker |
| Производительность | Высокая (Firecracker) | Средняя | Высокая |
| Безопасность | Полная изоляция ядра | Полная изоляция ядра | Разделяемое ядро |

## Решение ARIA
- **Primary (production):** E2B (Firecracker microVM) — полная аппаратная изоляция, мгновенные чекпоинты (DeltaBox), управление через MCP, оркестрация через KruiseAgents в K8s.
- **Secondary (dev/testing):** Daytona — резервный backend для сценариев, где не требуется полная интеграция с MCP.
- **Запрещён для critical workloads:** Docker.sandbox — контейнеризации недостаточно для защиты от атак на уровне ядра (подтверждено выводами Docker, 2026).

## Интеграция с Self-Correcting Agents
- **DeltaBox** используется для мгновенных чекпоинтов перед каждым действием агента.
- При обнаружении ошибки (OdabNote) или превышении лимита действий (Vibe Check) состояние sandbox откатывается к последнему чекпоинту.
- **Reflection Loop** выполняет повторную попытку с исправленными параметрами в восстановленной среде.

## Бенчмаркинг (ROADMAP v13.02)
- Latency запуска sandbox: <100ms (целевое значение)
- Потребление памяти: <128MB на sandbox
- Скорость создания чекпоинта: <10ms
- Скорость восстановления из чекпоинта: <10ms
- Безопасность egress: тест на DNS-туннелирование, блокировка нестандартных протоколов

## Мониторинг песочниц
- **Resource Abuse Detector** — детектор аномального потребления CPU/RAM/сети внутри sandbox.
- **Failure Clustering** — автоматическая группировка сбоев sandbox по первопричине.
- **Grafana MCP** — визуализация метрик всех активных sandbox.

## Принятые стандарты
- CoSAI MCP Security v1
- Microsandbox Isolation Mandate (аппаратная изоляция KVM)
- DeltaBox Sandbox Rollback Mandate (мгновенные чекпоинты)
