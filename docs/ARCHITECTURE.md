# ARCHITECTURE.md — Полная архитектура ARIA AI‑Factory v13.01

## 1. Архитектурные контуры

ARIA организована в 7 контуров:

- **Core** — стратегия, память, R&D.
- **Trading** — охота на MEV/манипуляторов.
- **CI/CD & Security** — детерминированные гарантии.
- **Interface** — командный центр, HITL.
- **Quantum Hub** — квантовые вычисления (резерв).
- **Autonomous Reproduction** — автономное воспроизводство кода.
- **Cryptographic Security** — квантово‑устойчивая защита (AES‑256‑GCM, RSA, Kyber, ZKP, MPC).

## 2. Сверх‑ядра (консолидированные модули)

| Сверх‑ядро | Назначение | Ключевые компоненты |
|:---|:---|:---|
| **Aria‑Cognitive‑Core** | Все инструменты рассуждения, анализа и принятия решений | Trinity Reasoning, Macro Analyst, EBM Engine, Bias Firewall, Deep Research, Expert Panel |
| **Aria‑Memory‑Core** | Динамический граф знаний и унифицированная память | **Graphiti** (темпоральный граф), **Beads** (версионируемая память задач), **Cognee** (самообучающаяся память), **LanceDB** (мультимодальное озеро данных), **Tradememory‑Engine** (торговая память), **SEmble** (сжатие эмбеддингов) |
| **Aria‑Sentinel‑Core** | Унифицированный детектор рыночных угроз | MEV‑Scanner, Market‑Maker‑Hunter, Coordinated‑Attack‑Detector, WashTradeDetector, SpoofDetector |
| **Aria‑Interface‑Hub** | Унифицированный HITL‑интерфейс | Telegram‑MCP, Interaction‑Model, Visual‑Insight, Dify‑Visualizer, Excalidraw, CopilotKit, OpenWebUI |
