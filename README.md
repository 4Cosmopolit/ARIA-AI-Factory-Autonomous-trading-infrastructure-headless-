# Polymarket AI-Factory

> **Автономная мультиагентная торговая инфраструктура.**
> Headless. Self-Hosted. Zero Hidden Cost.

## 🧠 Ключевые компоненты
- **ARIA Core:** 82-слойная рекурсивная архитектура (Мета-когнитивные навыки, Квантовый когнитивный слой, Темпоральное восприятие, Партнёрская модель Risk Officer, Автономная эволюция).
- **DuckDB:** Аналитическое ядро (OLAP, Векторная память на базе VSS, Полнотекстовый поиск, Макросы).
- **Агенты (8):** Spike Bot, Hunter, Onchain Detective, Cross-Exchange Arb, Sentiment Scout, Arbitrage Event Hunter, Mean Reversion, Market Maker Bot.
- **CI/CD:** Self-Hosted GitHub Actions, Docker Compose, Bifurcated Security Pipeline.
- **Безопасность:** 10 принципов безопасности, MEV Shield, Agent Session Guard, Catastrophe Guard, Hallucination Shield.
