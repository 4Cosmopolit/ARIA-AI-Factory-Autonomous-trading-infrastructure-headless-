# ARIA Factory Memory – Мета‑память инцидентов и решений

> **Назначение:** Хранить историю всех значимых решений и ошибок для непрерывной эволюции.  
> **Формат:** Инцидент # → Причина → Событие → Решение → Урок.

---

## Инциденты (выборка из 283)

### Инцидент #001 — IDOR-подобная уязвимость параметров
- **Причина:** отсутствие системной валидации входных параметров CLI и SQL
- **Событие:** анализ статьи Tushar Kanjariya показал, что невалидированный параметр может дать полный доступ
- **Решение:** создан навык security-guard с whitelist market_id, санитизацией CLI, аудитом всех команд
- **Урок:** никогда не доверять входным данным, даже если они внутренние

### Инцидент #010 — MCP признан мёртвым
- **Причина:** уязвимость RCE (CVE-2026-33032, рейтинг 9.8), налог на контекст
- **Событие:** индустрия признала MCP небезопасным и неэффективным
- **Решение:** отказ от MCP в пользу CLI+Skills
- **Урок:** следовать принципу KISS; безопасность превыше протоколов

### Инцидент #019 — Запрет внешних навыков (ClawHub)
- **Причина:** риск инъекций вредоносного кода через публичные репозитории навыков
- **Событие:** анализ ClawHub показал, что 1100+ навыков содержат вредоносный код
- **Решение:** vendor-independence — внешние навыки запрещены
- **Урок:** supply-chain безопасность — приоритет

### Инцидент #095 — Agent Session Guard
- **Причина:** OWASP Top 10 for Agentic AI (ASI01-ASI06)
- **Событие:** анализ угроз показал пробелы в сессионной безопасности агентов
- **Решение:** создан agent-session-guard с сессионной идентичностью и динамическими правами
- **Урок:** агенты должны иметь ограниченный срок жизни и минимальные привилегии

### Инцидент #110 — Финальный вердикт: MCP Is Dead
- **Причина:** статья Sudeep Devkota, поддержанная Theo (t3.gg) и Maximilian Schwarzmüller
- **Решение:** Agent Skills признаны стандартом, MCP — тупиковой ветвью
- **Урок:** мы были правы с самого начала

### Инцидент #165 — Cascade Guardian (OWASP ASI08)
- **Причина:** каскадные сбои в мультиагентных системах
- **Событие:** статья Will Velida и OWASP ASI08 Guide
- **Решение:** создан cascade-guardian с Semantic Circuit Breaker, Cross-Model Verification, Structured Error Response
- **Урок:** одна ошибка не должна парализовать всю фабрику

### Инцидент #195 — MEV Shield: трехуровневая защита
- **Причина:** MEV-бот украл $200K у участников аирдропа, Aave — $50M
- **Решение:** приватный мемпул, мониторинг, pre‑flight симуляция
- **Урок:** MEV-защита — не опция, а необходимость

### Инцидент #210 — Agent-in-the-Middle Guard
- **Причина:** arXiv:2603.22651 (MIT, UC Berkeley, Anthropic)
- **Решение:** трёхуровневая защита от атак через инструменты (pre‑tool validation, post‑tool monitoring, behavioral guardrails)
- **Урок:** даже собственные инструменты агента могут быть вектором атаки

### Инцидент #218–#284 — Полная интеграция Polymarket API
- **Причина:** необходимость запуска агентов на Polymarket
- **Событие:** изучено и интегрировано 45+ страниц официальной документации
- **Решение:** создано 45+ навыков, покрывающих все аспекты API (аутентификация, торговля, маркет-мейкинг, CTF, WebSocket, Bridge, Builder Program)
- **Урок:** фабрика полностью готова к запуску на Polymarket; ожидается Ed25519-ключ

### Инцидент #283 — Deposit Wallet Migration
- **Причина:** новый стандарт онбординга Polymarket (май 2026)
- **Решение:** создан навык polymarket-deposit-wallet для обхода KYC на этапе деплоя кошелька
- **Урок:** всегда следить за обновлениями платформы

## Правила пополнения
1. После каждого значимого инцидента ARIA-Auditor предлагает запись в этот файл
2. Risk Officer подтверждает или отклоняет запись
3. Каждая запись содержит: дата, причина, событие, решение, извлечённый урок, область применения
4. Записи используются для автоматического предотвращения аналогичных ситуаций
