# Polymarket AI-Factory Architecture (v0.2.0)

> Полная архитектура автономной мультиагентной торговой инфраструктуры.
> 120+ навыков, 8 агентов, 10 принципов, 270+ инцидентов.

## Ядро ARIA
82-слойная рекурсивная архитектура:
- Мета-Когнитивные Навыки
- Квантовый Когнитивный Слой
- Темпоральное Восприятие
- Партнёрская Глубинная Модель (Risk Officer)
- Рекурсивная Самокритика
- Непрерывная Эволюция (Continuous Evolution Runtime)
- Автономный API-клиент (DeepSeek)

## Агенты
- **Spike Bot:** ловит резкие движения рынка.
- **Hunter:** основной оппортунистический агент.
- **Onchain Detective:** анализирует блокчейн-данные.
- **Cross-Exchange Arb Agent:** арбитраж между биржами.
- **Sentiment Scout:** сканирует новостной фон.
- **Arbitrage Event Hunter:** ловит специальные события.
- **Mean Reversion Agent:** контр-трендовые сделки.
- **Market Maker Bot:** двусторонняя ликвидность.

## Аналитическое ядро
DuckDB с ART-индексами, векторной памятью (VSS), полнотекстовым поиском (FTS) и Parquet-пайплайнами.

## Безопасность
- 10 конституционных принципов
- MEV Shield (защита от сэндвич-атак)
- Agent Session Guard (сессионная идентичность)
- Catastrophe Guard (аварийный стоп)
- Hallucination Shield (четырёхуровневая защита от галлюцинаций)

## Инфраструктура
- Docker Compose (Kubernetes/Helm отвергнуты)
- Self-Hosted GitHub Actions
- Векторная память (DuckDB VSS)
- Полная интеграция с Polymarket API (45+ страниц документации)
