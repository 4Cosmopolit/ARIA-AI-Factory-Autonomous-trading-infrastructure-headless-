## 1. CEX-трейдинг (Bybit, Binance)

| Задача | Агенты | Периодичность | Статус |
|--------|--------|---------------|--------|
| Скальпинг на резких движениях (стакан, ликвидации) | Spike Bot | каждые 5–30 с | ⚡ активен |
| Трендовые входы (формации, пробои уровней) | Hunter | каждые 30–120 с | ⚡ активен |
| Средневозвратные стратегии (Боллинджер, RSI, выбросы) | Mean Reversion Agent | каждые 60 с | ⚡ активен |
| Кросс-биржевой арбитраж Bybit ↔ Binance | Cross-Exchange Arb Agent | real-time (стакан) | ⚡ активен |
| Арбитраж на событиях (листинги, делистинги, новости) | Arbitrage Event Hunter | реакция < 15 с | ⚡ активен |
| Маркет-мейкинг на низколиквидных парах (Bybit Spot) | Market Maker Bot | постоянно | ⚡ активен |

**Защита:**  
- Дневной убыток ≤ 1% от капитала.  
- Stop-Loss на всех позициях.  
- Проверка глубины стакана перед каждым ордером.  
- MEV-защита (сэндвич-атаки, 3-уровневый детектор).

## 2. DEX-трейдинг (Hyperliquid)

| Задача | Агенты | Статус |
|--------|--------|--------|
| On-chain разведка (потоки китов, ликвидность в пулах) | Onchain Detective | ⚡ активен |
| Средневозвратные стратегии на perps | Mean Reversion Agent | ⚡ активен |
| Пассивное маркет-мейкерство на избранных парах | Market Maker Bot | ⚡ активен |
| Арбитраж фандинга (Bybit Spot ↔ Hyperliquid Perps) | Cross-Exchange Arb Agent | ⚡ активен |

**Защита:**  
- Локальное хранение приватного ключа (подпись через `gateway`).  
- Максимальное проскальзывание 0.3%.  
- Fallback при неподтверждении транзакции за 3 блока.
